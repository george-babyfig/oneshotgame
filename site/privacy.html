English

Data Not Collected. Comet Garden has no accounts, ads, analytics or tracking. Progress and a small play ledger stay on this device. The Grown-ups area shows play time, purchases recorded here and settings. Apple processes purchases; we never see payment details. Optional reminders stay on the device. A tester build can copy a short Balance Report code only after an adult agrees; the code is not sent automatically. Shared challenge codes contain a planet code and score. For refunds and full purchase history, use Apple. Questions: visit our support page.

Español

Datos no recopilados. Comet Garden no tiene cuentas, anuncios, análisis ni seguimiento. El progreso y un pequeño registro de juego permanecen en este dispositivo. El área para adultos muestra el tiempo de juego, las compras registradas aquí y los ajustes. Apple procesa las compras; nunca vemos los datos de pago. Los recordatorios opcionales permanecen en el dispositivo. Una versión de prueba puede copiar un código breve del Informe de equilibrio solo con el consentimiento de un adulto; no se envía automáticamente. Los códigos de desafío compartidos contienen un código de planeta y una puntuación. Para reembolsos y el historial completo de compras, consulta Apple. Si tienes preguntas, visita nuestra página de soporte.

Français

L’espace Adultes affiche le temps de jeu, les achats enregistrés ici et les réglages. Apple traite les achats ; nous ne voyons jamais les données de paiement. Deutsch

Keine Daten erfasst. Comet Garden hat keine Konten, Werbung, Analyse oder Nachverfolgung. Spielfortschritt und ein kleines Spielprotokoll bleiben auf diesem Gerät. Im Bereich für Erwachsene stehen Spielzeit, hier erfasste Käufe und Einstellungen. Apple wickelt Käufe ab; Zahlungsdaten sehen wir nie. Optionale Erinnerungen bleiben auf dem Gerät. Eine Testversion kann einen kurzen Code des Balanceberichts nur mit Zustimmung eines Erwachsenen kopieren; er wird nicht automatisch gesendet. Geteilte Herausforderungscodes enthalten nur einen Planetencode und einen Punktestand. Erstattungen und die vollständige Kaufhistorie findest du bei Apple. Bei Fragen besuche unsere Support-Seite.

Português (Brasil)

Dados não coletados. Comet Garden não tem contas, anúncios, análises nem rastreamento. O progresso e um pequeno registro de jogo ficam neste aparelho. A área de adultos mostra tempo de jogo, compras registradas aqui e ajustes. A Apple processa as compras; nunca vemos dados de pagamento. Lembretes opcionais ficam no aparelho. Uma versão de teste pode copiar um código curto do Relatório de Equilíbrio apenas com o consentimento de um adulto; ele não é enviado automaticamente. Códigos de desafio compartilhados contêm somente um código de planeta e uma pontuação. Para reembolsos e o histórico completo de compras, consulte a Apple. Para dúvidas, acesse nossa página de suporte.

日本語

データは収集されません。Comet Gardenにはアカウント、広告、分析、追跡はありません。進行状況と小さなプレイ記録はこの端末に保存されます。保護者向けエリアにはプレイ時間、この端末で記録した購入、設定が表示されます。購入はAppleが処理し、開発者が支払い情報を見ることはありません。任意の通知も端末内にとどまります。テスト版では、大人の同意後にのみ短いバランスレポートのコードをコピーできます。自動送信はされません。共有するチャレンジコードには惑星コードとスコアだけが含まれます。返金と完全な購入履歴はAppleで確認してください。ご質問はサポートページからお問い合わせください。
