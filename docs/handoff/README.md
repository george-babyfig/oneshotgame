# Handoff: Comet Garden (developed as "Pocket Planet")

These files carry the full context of the three build sessions so far (two in the cloud on 27–28 September 2026, then the first **local** one on the owner's Mac on 28–30 September, which built milestones M0–M8 plus launch prep), so a new local session, with Codex as lead developer, can continue from **M9 (Remix)** without losing anything.

The game's player-facing name is now **Comet Garden**, renamed from Pocket Planet after App Store research found the old name taken (see [01-history.md](01-history.md) §31). The repo, the bundle ID (`com.pocketplanet.game`), every in-app purchase product ID and every Game Center ID still read `pocketplanet` on purpose.
